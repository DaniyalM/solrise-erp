# Inventory

- `hosts.ini` — **generated by Terraform** (`infra/terraform apply`) from the live
  Elastic IP. Gitignored. This is the default inventory in `ansible.cfg`.
- `aws_ec2.yml` — dynamic inventory that discovers the host by its
  `Role=solrise-app` tag. Use it once the stack exists and you have AWS
  credentials on the control node:

  ```bash
  ansible-playbook -i inventory/aws_ec2.yml site.yml
  ```

Do not commit `hosts.ini`; it is environment-specific and points at a real host.
